# Parquet Studio

`ratatui` と `polars` を使った、データセット作成向けの Parquet 専用 TUI エディターです。

## 起動

Rust の安定版ツールチェーンとネイティブビルド環境が必要です。Windows では MSVC 用の C++ Build Tools を使用してください。

```powershell
cargo run --locked
cargo run --locked -- dataset.parquet
```

引数のファイルが存在すれば読み込み、存在しなければそのパスを保存先として新規作成します。引数なしで起動すると、最初の保存時にパスを入力します。初回ビルドは Polars のコンパイルに時間がかかります。

```powershell
cargo build --locked --release
.\target\release\parquet-editor.exe dataset.parquet
```

## 操作

| キー | 操作 |
| --- | --- |
| `C` | 列を追加。名前を入力し、`Tab` / `↑` / `↓` で型を切り替え、`Enter` で確定 |
| `R` | 末尾に NULL の行を追加 |
| `Enter` / `F2` | セルの編集。`Enter` で確定、`Esc` で取り消し |
| `Alt+Enter` / `Shift+Enter` | 編集中のセルに改行を挿入（端末の対応状況によります） |
| `Ctrl+U` | 編集中のテキストをクリア |
| `Ctrl+Delete` / `Delete` | 選択セルの内容を削除するか確認。`Y`でNULLにし、`N` / `Esc`でキャンセル。`Ctrl+Z`で復元可能 |
| `Ctrl+,` / `F4` | 設定画面を開く。言語・ページの表示行数と列数を変更 |
| `Ctrl+S` | 上書き保存。未確定のセル入力も確定して保存 |
| `Ctrl+Q` | 終了。未保存の変更があれば `Y` で保存して終了、`N` で破棄して終了、`Esc` で戻る |
| `Ctrl+Z` | 直前の変更を元に戻す（最大100回。セル編集・行追加・列追加が対象） |
| `Ctrl+C` / `Ctrl+V` | 選択セル全体をコピー / 貼り付け。編集画面ではカーソル位置に貼り付け |
| `↑` / `↓` / `←` / `→` | セル間を移動 |
| `PageUp` / `PageDown` | 前 / 次の行ページ |
| `Tab` / `Shift+Tab` | 次 / 前の列ページ |
| `Home` / `End` | 先頭 / 末尾の列。`Ctrl` を併用すると行も先頭 / 末尾へ移動 |
| `F6` | セル → 行全体 → 列全体の選択を切り替え |
| `Shift+Space` / `Ctrl+Space` | 行全体 / 列全体を選択（端末がキーを転送しない場合は `F6`） |
| `Esc` | セル選択に戻す |
| `[` / `]` | ページの表示行数を減らす / 増やす（10・20・30・50・100） |
| `-` / `+` | ページの表示列数を減らす / 増やす（2・3・4・6・8） |
| `F1` / `?` | ヘルプ |

セル・行番号・列見出しはマウスでも選択できます。選択した行・列は画面内の全体がハイライトされます。下部の「行数」/「列数」（英語では `Rows` / `Cols`）の `[-]` / `[+]` ボタンで表示件数を切り替え、`<R` / `R>` / `<C` / `C>` ボタンでページを移動できます。行・列全体の選択中でも、セル削除の対象は現在位置の1セルだけです。行・列の数や位置は変わりません。

表示件数は端末の大きさに合わせて制限され、下部の「表示枠」（英語では `view`）に実際の表示枠数を示します。最小端末サイズは55列×18行です。Windows Terminal など、Unicode に対応した端末での利用を推奨します。

## 言語と設定

初期言語は日本語です。`Ctrl+,` で設定を開き、`↑` / `↓` で項目を選択、`←` / `→` で値を変更します。`Enter`（または設定画面内の `Ctrl+S`）で設定を保存・適用し、`Esc` / `Ctrl+,` で取り消します。言語の変更候補は設定画面でプレビューできます。端末が `Ctrl+,` を転送できない場合は `F4` でも開閉できます。

言語（`ja_JP` / `en_US`）・ページの行数・列数をOS標準のアプリ設定ディレクトリ内の `settings.json` に保存し、次回起動時に復元します。保存先は設定画面に表示します。`PARQUET_EDITOR_CONFIG` 環境変数で保存先を指定することもできます。下部ボタンで変更した表示件数も、設定画面を開いて確定すれば保存されます。

```json
{
  "language": "ja_JP",
  "rows_per_page": 20,
  "columns_per_page": 4
}
```

設定の保存とParquetの保存は別です。設定変更でデータセットのUndo履歴や保存済み状態は変わりません。編集中に設定を開いても、閉じると編集中の入力に戻ります。設定の読み込みに失敗した場合は既定値で起動してエラーを表示し、保存に失敗した場合は適用前の設定と変更候補を保持します。

翻訳文言は `translate/ja_JP.json` と `translate/en_US.json` に格納しています。画面・ヘルプ・ステータス・アプリ固有のエラー・CLIヘルプを同じ翻訳キーで管理します。OSやPolarsが返す詳細なエラーは元の文言を添えます。翻訳JSONはビルド時に実行ファイルへ埋め込むため、実行時の作業ディレクトリには依存しません。翻訳を変更した場合は再ビルドしてください。未定義キーは英語へフォールバックします。

## データの扱い

- 新規列の型は `String`・`Int64`・`Float64`・`Boolean`・`UInt64`。既存の整数型・浮動小数点型も型を維持して編集します。範囲外の数値や型に合わない入力は確定できません。
- NULL と空文字列は別の値です。NULL は `∅ NULL`、空文字列は `""` と表示します。空の編集を確定すると空文字列になり、`Ctrl+Delete` / `Delete` の確認で `Y` を押すと NULL になります。テキスト編集中の通常の `Delete` はカーソル位置の文字を消します。
- 日本語・絵文字・改行・タブを含む文字列を保持します。表では改行を `↵`、タブを `⇥` と表示し、下部に選択セルをプレビューします。複数行のクリップボード文字列も1セルとして貼り付けます。
- 日付・時刻・リスト・構造体などの既存列は、値と型を保持して読み込み・保存します。これらの型の非NULL値の編集には対応していません。
- OS のクリップボードを利用できない環境では、アプリ内コピーへフォールバックします。アプリ内でコピーした NULL は NULL として貼り付けます。外部アプリへは空文字列としてコピーされます。
- 保存は同じディレクトリ内の一時ファイルに書き込み、フラッシュが成功してから保存先を置き換えます。新しい保存先に既存ファイルがある場合は上書きを確認します。保存に失敗した場合は編集状態を保持します。
- ファイル全体をメモリーに読み込みます。Undo は Polars の列バッファーを共有しますが、変更した列の履歴に応じてメモリーを使用します。巨大ファイルのストリーミング編集、外部からの同時変更の検知、元ファイル固有の Parquet メタデータ・圧縮設定の保持には対応していません。
- キー操作には端末側の割り当てが影響します。`Ctrl+V` を端末の貼り付けに割り当てている場合も、対応端末の bracketed paste を処理します。
